Zones — set by the network, not by you

Everyone in a network uses the same zones. A reading is only comparable to another reading drawn on the same partition — change where the lines are and the same books produce a different number. Within one network with fixed zones you can compare firms to each other and yourself to yourself over time. Across networks drawn differently, you cannot, and nothing here claims you can.
Everything else is far. Blank zip or 99999 is void — money whose trail ends. City and county resolve from a pilot table that covers a few Arkansas counties and is a placeholder until real HUD data is imported — check the resolved list below before trusting it.
